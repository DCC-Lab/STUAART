\doxysubsection{Detailed Description}
This library extends the functionality of the HX711 to make it compatible with the \doxylink{class_load_cell_controller}{Load\+Cell\+Controller} library. 

This Arduino library allows to specify the number of readings averaged for the three possible situations\+:
\begin{DoxyItemize}
\item Weight reading
\item Output reading for offset calibration
\item Output reading for scale coefficient calibration
\end{DoxyItemize}

The encapsulation of these parameters requires the rewriting of a few member functions of the HX711 library. They do the same thing but, with the encapsulation of the three paramters listed above, they don\textquotesingle{}t require any arguments.

Most importantly, the encapsulation of these parameters is useful for the \doxylink{class_load_cell_controller}{Load\+Cell\+Controller} library, which will control many Load\+Cells.

HX711 library\+: \href{https://github.com/bogde/HX711}{\texttt{ https\+://github.\+com/bogde/\+HX711}}
