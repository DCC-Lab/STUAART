\doxysubsection{Detailed Description}
This library allows to control and manage many load cells with a \doxylink{class_load_cell_controller}{Load\+Cell\+Controller}. 

The \doxylink{class_load_cell_controller}{Load\+Cell\+Controller} library offers many features\+:


\begin{DoxyItemize}
\item Calibrate load cells, both parameters (offset and scale coefficient)
\begin{DoxyItemize}
\item Member functions encapsulate the scripts needed for the calibration for both parameters. The interaction with the user is done inside the member functions.
\end{DoxyItemize}
\item Save the calibration parameters to EEPROM (tested on Arduino Uno August 2023)
\begin{DoxyItemize}
\item The calibration parameters can be saved on the EEPROM after calibration. The EEPROM is useful when it comes to saving because the saved values don\textquotesingle{}t vanish when the power supply of the Arduino is cut. The saved parameters can be reused at another moment.
\end{DoxyItemize}
\item Read the calibration parameters from EEPROM (tested on Arduino Uno August 2023)
\begin{DoxyItemize}
\item The calibration parameters can also be read from EEPROM after being saved.
\end{DoxyItemize}
\item \"{}\+Easy\"{} start-\/up function that will handle everything related to the calibration and manage the calibration parameters.
\begin{DoxyItemize}
\item The \doxylink{class_load_cell_controller}{Load\+Cell\+Controller} class offers ready-\/to-\/use \"{}easy\"{} functions that simplify the start-\/up of a load cell. Many scenarios are possible for the start-\/up of a load cell when it comes to calibration and the management of the calibration parameters.
\item A simple function \doxylink{class_load_cell_controller_ab541e7609395928262857c32192ebb08}{easy\+\_\+start\+\_\+with\+\_\+params()} takes in arguments many parameters to choose the appropriate option. Only a few parameters are needed.
\item This is useful for those who don\textquotesingle{}t want to create their own sketch.
\item All the member functions that begin with \"{}easy\"{} are for easy start-\/up and don\textquotesingle{}t implement any other functionalities than the other member functions. They only offer a \"{}all-\/in-\/one\"{} option for those who don\textquotesingle{}t want to code.
\end{DoxyItemize}
\item The \doxylink{class_load_cell_controller}{Load\+Cell\+Controller} class allows to access the load cells through the controller.

The load cells are added with the member function \doxylink{class_load_cell_controller_a81fb15d14c2c3d6dab3769f44d2fb9bd}{add\+\_\+loadcell()}. After that, all load cells are under the control of the \doxylink{class_load_cell_controller}{Load\+Cell\+Controller} and the member functions of the \doxylink{class_load_cell}{Load\+Cell} class are accesed through the controller.

This access to the Load\+Cells through the \doxylink{class_load_cell_controller}{Load\+Cell\+Controller} requires to specify to \doxylink{class_load_cell_controller}{Load\+Cell\+Controller} a parameter corresponding to the number identifying the \doxylink{class_load_cell}{Load\+Cell} concerned (1, 2, ...). Every member functions that have as input the number of a \doxylink{class_load_cell}{Load\+Cell} (n\+\_\+loadcell) will verify if the \doxylink{class_load_cell}{Load\+Cell} number is in a coherent range according to the number of Load\+Cells added to the controller according to the member variable \doxylink{class_load_cell_controller_a233d1a7d5a09e65b99e68bb7458d7715}{n\+\_\+loadcell}. If the value is out of the range, the code will be suspended with a endless while() loop and display on the serial monitor an error message specifying where the problem occured (in which function). Proceed to the calibration of the scale coefficient and return the scale coefficient value. 

This function interacts with the user through the serial monitor to get a scale coefficient value for a given \doxylink{class_load_cell}{Load\+Cell}.

This member function asks the user to specify the number of reference weights that will be used to calibrate the load cell.

After that, the user is asked to put the first reference weight on the loadcell and send the weight value through the serial monitor. A weight measurement is done using the member function \doxylink{group___load_cell_ga596e9234d568399c3f8a42b9256fc47d}{read\+\_\+scale\+\_\+coeff\+\_\+average()}. A couple for our calibration linear function -\/\texorpdfstring{$>$}{>} output = scale\+\_\+coeff \texorpdfstring{$\ast$}{*} mass + offset is obtained (known mass, measured output). The scale coefficient can now be calculated.

The process described above can be repeated for each reference weight to get a scale coefficient value.

The average of all scale coefficients is taken to get the finale value returned by the function.

\begin{DoxyNote}{Note}
With this simple method, the scale coefficient depends of the offset. Finding both calibration parameters (offset and scale coefficient) at the same time with a curve fit algorithm could be more effective.
\end{DoxyNote}
